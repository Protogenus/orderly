Orderly 0.1.0 - "Every order, in order."
Clever Signal - order management and fulfillment for independent makers.

TO RUN
  1. Extract this zip to any folder (keep the folder structure).
  2. Double-click START_ORDERLY.bat.

Your data is stored on your own computer in:
  %APPDATA%\Orderly\
Nothing is sent to the internet. No account needed.

BACKUPS
  Use Settings > Backup inside the app to save a backup file,
  and Settings > Restore to bring one back.

SUPPORT FILES
  win-unpacked/  - the application itself (do not move files out of it)
  START_ORDERLY.bat - launcher (this file's folder is the install location)
